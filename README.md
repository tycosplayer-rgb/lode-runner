# 淘金者 · Lode Runner

红白机 / NES 风格的 **Lode Runner（淘金者）** 浏览器复刻：挖洞、爬梯子、攀绳子、捡金子、躲避敌人。

> 注意：这是经典 NES《淘金者 / Lode Runner》，**不是**夹娃娃式的「黄金矿工」钩爪游戏。

## 在线游玩

**https://tycosplayer-rgb.github.io/lode-runner/**

手机请**横屏**；竖屏会提示「请横屏游玩」。

## 本地运行

直接打开：

```bash
open index.html
# 或双击 index.html
```

或用本地静态服务：

```bash
npx --yes serve .
# 然后打开提示的地址
```

## 操作说明

| 操作 | 键盘 | 触屏（横屏） |
|------|------|--------------|
| 移动 / 爬梯 / 攀绳 | 方向键 ←→↑↓ | 左侧方向键 |
| 向左挖洞 | `Z` | 右侧「挖左」 |
| 向右挖洞 | `X` | 右侧「挖右」 |
| 暂停 | `P` | — |
| 本关重开 | `R` | — |

## 玩法

1. 收集关卡内全部金子  
2. 出口梯子出现后，爬到地图最上方过关  
3. `Z` / `X` 挖掉脚下左右的砖块，砖块稍后会恢复  
4. 敌人掉进洞会被困；洞填上时敌人消灭并重生；你可从被困敌人头上走过  
5. 共有 **6** 关，难度递增；初始 3 条命  

## 技术

- HTML5 Canvas + 原生 JavaScript + CSS  
- 无框架、无构建步骤  
- 横屏优先布局；竖屏旋转提示；触屏虚拟按键
